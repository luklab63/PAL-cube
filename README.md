# PAL V2 

## electronics 

* ESP32 C6 devmodule
* 2x SG90 servo moteurs 
* SH1106 0.94" OLED screen 
* power switch 
* small batterie bank 
* used usb cable 
* PCB 

## The PCB 

it is a simple PCB that holds the ESP32 the batterie connector and the screen and servo connectors. it is 70 x 60 mm
